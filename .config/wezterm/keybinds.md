# WezTerm キーバインド仕様

Leader キー: `Ctrl + q`（2000ms タイムアウト）

## ワークスペース

| キー | 動作 |
|---|---|
| `Leader + w` | ワークスペース一覧を表示・切り替え |
| `Leader + $` | 現在のワークスペースをリネーム |
| `Leader + Shift + W` | 新規ワークスペースを作成 |

## タブ

| キー | 動作 |
|---|---|
| `Cmd + t` | 新規タブを開く |
| `Cmd + w` | 現在のタブを閉じる（確認あり） |
| `Ctrl + Tab` | 次のタブへ |
| `Ctrl + Shift + Tab` | 前のタブへ |
| `Cmd + {` | 前のタブへ |
| `Cmd + }` | 次のタブへ |
| `Leader + {` | タブを左に移動 |
| `Leader + }` | タブを右に移動 |
| `Cmd + 1〜8` | 番号でタブを指定 |
| `Cmd + 9` | 最後のタブへ |

## ペイン

| キー | 動作 |
|---|---|
| `Leader + d` | 縦に分割（上下） |
| `Leader + r` | 横に分割（左右） |
| `Leader + x` | 現在のペインを閉じる（確認あり） |
| `Leader + h/j/k/l` | 左/下/上/右のペインへ移動 |
| `Leader + z` | 現在のペインを最大化トグル |
| `Ctrl + Shift + [` | ペインを選択して移動 |
| `Leader + e` | broot をファイラーとして左ペインにトグル表示 |

### ペインサイズ調整モード（`Leader + s`で開始）

| キー | 動作 |
|---|---|
| `h / l / k / j` | 左/右/上/下に1単位ずつリサイズ |
| `Enter` | モードを終了 |

### ペイン直接移動モード（`Leader + a`で開始、1000msタイムアウト）

| キー | 動作 |
|---|---|
| `h / l / k / j` | 左/右/上/下のペインへ移動 |

## コピー・ペースト

| キー | 動作 |
|---|---|
| `Cmd + c` | クリップボードにコピー |
| `Cmd + v` | クリップボードから貼り付け |
| `Leader + [` | コピーモードに入る |

### コピーモード（`Leader + [`で開始）

**移動**

| キー | 動作 |
|---|---|
| `h / j / k / l` | 左/下/上/右 |
| `w / b / e` | 単語単位で前/後/末尾に移動 |
| `0` | 行の先頭へ |
| `^` | 行の最初の非空白文字へ |
| `$` | 行の末尾へ |
| `g` | スクロールバック最上部へ |
| `G` | スクロールバック最下部へ |
| `H / M / L` | ビューポートの上/中/下へ |
| `Ctrl + b / f` | 1ページ上/下へ |
| `Ctrl + u / d` | 半ページ上/下へ |

**ジャンプ**

| キー | 動作 |
|---|---|
| `f {char}` | 指定文字に前方ジャンプ |
| `F {char}` | 指定文字に後方ジャンプ |
| `t {char}` | 指定文字の直前に前方ジャンプ |
| `T {char}` | 指定文字の直前に後方ジャンプ |
| `;` | 直前のジャンプを繰り返す |

**選択**

| キー | 動作 |
|---|---|
| `v` | 文字単位で選択開始 |
| `V` | 行単位で選択開始 |
| `Ctrl + v` | ブロック選択開始 |
| `o` | 選択範囲の反対端へ移動 |
| `O` | 選択範囲の水平方向の反対端へ移動 |

**確定・終了**

| キー | 動作 |
|---|---|
| `y` | クリップボードにコピー |
| `Enter` | コピーしてモード終了 |
| `Escape / q / Ctrl + c` | コピーモードを終了 |

## その他

| キー | 動作 |
|---|---|
| `Alt + Enter` | フルスクリーン切り替え |
| `Cmd + p` | コマンドパレット |
| `Ctrl + Shift + p` | コマンドパレット |
| `Ctrl + Shift + r` | 設定を再読み込み |
| `Ctrl + +` | フォントサイズを大きく |
| `Ctrl + -` | フォントサイズを小さく |
| `Ctrl + 0` | フォントサイズをリセット |
